# Design Patterns

This directory contains Python exercises focused on design patterns and object-oriented software design.

## Topics

- Design patterns
- Creational, behavioral, and structural patterns
- Factory pattern
- Observer pattern
- Decorator pattern
- Object creation and registration
- Event notification and subscription
- Composition over inheritance
- Open/Closed Principle
- Maintainable and extensible software design

## Files and Description

| **File** | **Description** |
| --- | --- |
| `0-factory.py` | Extends a vehicle factory registry to support a new vehicle type without modifying the factory's creation logic. |
| `1-observer.py` | Implements an SMS observer that receives only breaking-news notifications. |
| `2-decorator.py` | Implements a caramel decorator that adds cost and description to a beverage by wrapping existing objects. |
