# UML Introduction

This directory contains exercises focused on UML modeling using Mermaid class and sequence diagrams.

## Topics

* UML class diagrams
* UML sequence diagrams
* Classes, attributes, and methods
* Class responsibilities
* Relationships between classes
* Multiplicity
* Object interactions
* Association
* Generalization
* Aggregation
* Composition
* Realization
* Dependency
* Mermaid syntax

## Files and Description

| **File**                 | **Description**                                                                                                                         |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| `0-class_diagram.mmd`    | Defines a Mermaid class diagram for the Library Loan System, including classes, attributes, methods, relationships, and multiplicities. |
| `1-sequence_diagram.mmd` | Defines a Mermaid sequence diagram showing how a user borrows a book from the library.                                                  |
