# Software Design & Architecture

This repository contains projects focused on software design, UML modeling, and software architecture.

## Topics

* Unified Modeling Language (UML)
* Class diagrams
* Sequence diagrams
* Classes, attributes, and methods
* Relationships between classes
* Association
* Generalization
* Aggregation
* Composition
* Realization
* Dependency
* Multiplicity
* Mermaid diagrams
* Software system modeling
