# Software Design & Architecture

This repository contains projects focused on software design, UML modeling, design patterns, and software architecture.

## Topics

- Unified Modeling Language (UML)
- Class diagrams
- Sequence diagrams
- Classes, attributes, and methods
- Relationships between classes
- Association
- Generalization
- Aggregation
- Composition
- Realization
- Dependency
- Multiplicity
- Mermaid diagrams
- Software system modeling
- Design patterns
- Factory pattern
- Observer pattern
- Decorator pattern
- Object-oriented design principles
- Open/Closed Principle
- Composition over inheritance
- Maintainable and extensible software design

## Directories

| **Directory** | **Description** |
| --- | --- |
| `uml_intro` | Introduces UML modeling through class diagrams, sequence diagrams, and relationships between classes. |
| `design_patterns` | Explores creational, behavioral, and structural design patterns using Python, including Factory, Observer, and Decorator. |
